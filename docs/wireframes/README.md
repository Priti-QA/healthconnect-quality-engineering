
# HealthConnect Wireframes

This folder contains application wireframes and screen designs for the HealthConnect healthcare management application.

## Planned Screens

1. Patient Registration Screen
2. Patient Login Screen
3. Patient Dashboard
4. Doctor Search Screen
5. Appointment Booking Screen
6. Appointment History Screen
7. Appointment Cancellation Screen
8. AI Healthcare Assistant Screen

## Objective
To define the application layout, navigation, user interactions and screen-level requirements before development.

## Status
Wireframes will be added during the design phase.
