
# AI Testing

This folder contains test scenarios, test data and automation scripts for evaluating the HealthConnect AI Healthcare Assistant.

## Tools and Technologies
- Python
- Pytest
- AI Evaluation Techniques
- REST APIs
- JSON

## Testing Scope
- AI Response Accuracy
- Response Relevance
- Hallucination Testing
- Prompt Injection Testing
- Privacy and Data Protection Testing
- AI Response Consistency
- Safety and Responsible AI Testing

## Project Activities
- Validate AI assistant responses
- Identify incorrect or misleading responses
- Test inappropriate medical advice scenarios
- Verify protection against patient data exposure
- Evaluate response quality and relevance
- Document AI-related defects

## Objective
To evaluate the accuracy, reliability, privacy and safety of AI-powered application features.

## Status
Currently under development.
