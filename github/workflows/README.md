
# GitHub Actions – CI/CD Workflows

This folder contains GitHub Actions workflow configurations for continuous integration and continuous testing of HealthConnect.

## Tools and Technologies
- GitHub Actions
- Git
- Maven
- Java
- Node.js
- Selenium
- TestNG
- Rest Assured

## CI/CD Activities
- Automated application build
- Backend build validation
- Frontend build validation
- API automation execution
- UI automation execution
- Test report generation
- Pipeline execution monitoring
- Quality gate validation

## Objective
To integrate automated testing into the development lifecycle and ensure continuous application quality.

## Status
CI/CD workflows will be configured during the integration phase.
