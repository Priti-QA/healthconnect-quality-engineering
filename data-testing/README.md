
# Data Testing

This folder contains SQL and Python-based database testing and data validation scripts.

## Tools and Technologies
- PostgreSQL
- SQL
- Python
- Pandas
- Pytest

## Testing Scope
- Database validation
- Data integrity testing
- Source-to-target data validation
- Record count verification
- Duplicate record identification
- Null value validation
- Data reconciliation
- Data consistency testing

## Project Activities
- Validate patient records
- Verify doctor information
- Validate appointment records
- Compare API responses with database records
- Identify missing and duplicate records
- Verify data accuracy after appointment booking and cancellation

## Objective
To ensure data accuracy, completeness, consistency and integrity across the HealthConnect application.

## Status
Currently under development.
