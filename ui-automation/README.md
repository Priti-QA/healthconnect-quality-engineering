
# UI Automation

This folder contains the Selenium WebDriver automation framework for the HealthConnect application.

## Tools and Technologies
- Java
- Selenium WebDriver
- TestNG
- Maven
- Page Object Model (POM)
- Allure Reports

## Automation Scope
- Patient Registration
- Patient Login
- Doctor Search
- Appointment Booking
- Appointment Cancellation
- Appointment History
- Form Validation
- Error Message Validation
- Role-Based Access Testing

## Framework Features
- Reusable automation methods
- Page Object Model
- Data-Driven Testing
- Explicit Waits
- TestNG Assertions
- Screenshot Capture
- Test Execution Reporting

## Objective
To develop a reusable, maintainable and scalable UI automation framework.

## Status
Currently under development.
