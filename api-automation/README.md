# API Automation

This folder contains API testing and automation scripts for the HealthConnect application.

## Tools and Technologies
- Postman
- REST Assured
- Java
- Maven
- TestNG

## Testing Scope
- REST API testing
- HTTP methods validation (GET, POST, PUT, DELETE)
- Request and response validation
- HTTP status code validation
- JSON schema validation
- Authentication and authorization testing
- API negative testing
- API and database integration testing

## Project Modules
- Patient Registration API
- Patient Login API
- Doctor Search API
- Appointment Booking API
- Appointment Cancellation API
- Appointment History API

## Objective
To validate API functionality, reliability, data integrity and integration between application components.

## Status
Currently under development.
